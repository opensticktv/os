# First-run flow

1. Language picker (any remote, including the TV remote over CEC).
2. Network: Ethernet skips this. Otherwise the TV shows a QR code; scanning it joins the phone to a temporary `OpenStick-XXXX` access point and opens a page to pick the home Wi-Fi. On-screen keyboard fallback is always available.
3. Google Chrome: show Google's terms; on accept, install into `vendor`. Skippable.
4. Optional: device name, remote pairing, Home Assistant / HomeKit / Matter.
5. Home screen. Target: under five minutes.
