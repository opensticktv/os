# Preinstalled OpenStick apps

| App | Repo | Needs from the platform |
| --- | --- | --- |
| OpenStick launcher | [launcher](https://github.com/opensticktv/launcher) | Home screen role (Operator Tier) or normal app (retail Google TV) |
| openstickd | [openstickd](https://github.com/opensticktv/openstickd) | Persistent background service, HDMI-CEC control, network discovery (mDNS), boot start |
| FCast receiver | upstream | Network discovery, run in background |
| DLNA renderer | to be chosen | Network discovery, run in background |
| Privacy disclosure | launcher | Shown during first run |

Every privilege must be agreed with the partner before the contract is signed.
